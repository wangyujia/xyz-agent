# 云服务影像同步与断点续传

## 概述

支持相册文件自动/手动同步至云端，采用增量策略避免重复传输，断点续传保障大文件可靠上传。

## 1. 影像同步

### 同步模式

| 模式 | 触发 | 说明 |
|------|------|------|
| 自动同步 | 满足前置条件时自动 | 无需用户操作 |
| 手动同步 | 用户在相册中选择 | 支持全选、批量、勾选、单选 |
| 立即同步 | 用户在云服务入口点击 | 触发前置校验后开始 |

### 同步后删除

- **开启**：同步完成后删除本地原文件
- **未开启**：同步完成后保留原文件
- ⚠️ 异常中断时：即使开启了自动删除，未成功同步的文件必须保留

### 同步范围

仅限相册页可显示的文件，包括：
- 内置存储的相册文件
- 存储卡的相册文件

## 2. 增量同步

**原则**：只同步新增或变化的文件，已在云端的不重复传输

- 自动同步：自动跳过已存在于云端的文件
- 手动同步：需让用户**明确感知**哪些文件已存在云端（UI 标记）

## 3. 断点续传

### 触发场景

断网、断电、强制关机等导致传输中断后，设备满足前置校验时自动恢复。

### 处理流程

```
相机 → 向云端发起校验请求
       （比对中断文件的 MD5 + 已接收分片进度）
         ↓
云端 → 返回断点位置（已完成的最后一个分片）
         ↓
相机 → 从断点继续上传（非从 0% 重新开始）
```

### 关键设计

- 文件校验：MD5 比对确保数据一致性
- 分片粒度：按文件切片上传（切片大小待定义）
- 断点信息：云端记录每个文件的已接收分片

## 同步优先级

当相机和存储卡自动同步都开启时：
- **优先上传相机文件**，再上传存储卡文件

## 同步顺序

| 选项 | 说明 | 默认 |
|------|------|------|
| 最早拍摄 | 时间从远到近 | ✅ 默认 |
| 最近拍摄 | 时间从近到远 | |
