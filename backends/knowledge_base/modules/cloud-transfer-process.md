# 云服务传输流程与前置校验

## 概述

云传输启动前需通过一系列前置校验，传输过程中有完整的状态展示和保护机制。

## 1. APP 连接断开

传输开始时，相机**主动断开与 APP 的连接**，释放网络模块用于 WiFi 云传输。

适用场景：自动同步 / 立即同步 / 手动同步

## 2. 前置校验（按顺序）

| 序号 | 校验项 | 条件 | 不满足时 |
|------|--------|------|---------|
| 1 | 权益校验 | 账号有云同步订阅/试用权益 | 拦截 + 引导订阅 |
| 2 | WiFi 校验 | 相机已成功连接 WiFi | 拦截 + 提示配置 WiFi |
| 3 | 电量校验 | 见下方详细规则 | 拦截 + 提示充电 |
| 4 | 温度校验 | 相机温度 < 二级温控 | 拦截 + "相机高温，请静置后重试" |
| 5 | 状态校验 | 相机处于空闲/无拍录任务 | 拦截 + 提示关闭任务 |

### 电量校验详细规则

| 同步类型 | 条件 |
|---------|------|
| 自动同步（充电优先） | 连接电源 + 电量 ≥ 80% |
| 自动同步（同步优先） | 连接电源 + 电量 ≥ 40% |
| 立即同步/手动同步 | 电量 ≥ 40% |

### 相机空闲状态定义

- 处于熄屏或预览状态
- 无任何拍录任务运行

## 3. 传输状态显示

### 3.1 屏幕信息

| 显示项 | 格式 | 说明 |
|--------|------|------|
| WiFi 名称 | SSID 文本 | 确认网络环境 |
| 传输速度 | 100 MB/s 或 512 KB/s | <1MB 时切换为 KB/s |
| 剩余时间 | 基于速度 + 剩余大小预估 | 动态更新 |
| 任务进度 | 第 X/Y 个文件 | 总量感知 |

### 3.2 指示灯

- 传输中：**绿灯常亮** + **蓝灯呼吸闪烁**（3s 一次，渐亮渐灭）

### 3.3 手动取消

- 支持用户手动取消同步
- 取消前需**确认动作**（防误操作）
- 取消后显示：已完成同步 X/Y 个文件
- 单文件传输被中断 → 该文件视为未完成

## 4. 同步完成行为

| 同步类型 | 完成后行为 |
|---------|-----------|
| 自动同步 | 显示"同步完成" → 5s 关机倒计时 → 自动关机 |
| 手动同步 | 显示"同步完成" + 完成 icon → 点击后跳转上一级 |
| 立即同步 | 显示"同步完成" + 完成 icon → 点击后跳转上一级 |

## 5. 传输中限制

- ❌ 不支持任何拍录任务
- ❌ 禁用离线语音词
- ❌ 禁用手势识别

## 6. 与 APP/服务端协同

- 同步**开始**时：通知 APP（服务端）传送状态
- 同步**结束**时：通知 APP（服务端）传送状态
