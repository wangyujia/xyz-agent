# 云服务鉴权与绑定

## 概述

相机通过 SN + Secret 向 Leaptic 服务器获取 UAT (User Access Token)，实现免人工干预的自动鉴权。

## 1. 绑定流程（首次开通）

```
相机 → 提示用户通过 APP 开通云服务
         ↓
APP → 开通云服务 + 订阅
         ↓
APP → 上传 账号+设备+订阅信息 至服务端
         ↓
服务端 → 绑定三者 → 下发 云服务 Secret 给 APP
         ↓
APP → 通过蓝牙将 Secret 传输至相机
         ↓
相机 → 存储 Secret，后续连接时使用
```

## 2. 自动鉴权（OAuth 逻辑）

**触发时机**：相机连接公网 + 用户手动/自动发起云同步

**流程**：
1. 相机用 **SN 号 + 云服务 Secret** 向服务器发起鉴权请求
2. 服务器验证通过 → 返回有时效性的 **UAT**
3. 相机后续所有 API 调用携带 UAT 进行身份验证

**UAT 生命周期**：
- 有效期：约 1 周
- 过期后：重新向服务器申请
- 主动续期：在过期前 **1 小时** 提前请求新 UAT（活跃状态下）

## 3. 心跳机制

- 相机与云服务之间维持心跳包
- 用途：维持连接状态 + 实时感知断连
- 断连后触发自动重连流程

## 关键凭据

| 凭据 | 存储位置 | 来源 | 用途 |
|------|---------|------|------|
| SN 号 | 相机固件 | 出厂写入 | 设备身份标识 |
| 云服务 Secret | 相机存储 | 服务端签发→APP→蓝牙→相机 | 鉴权请求凭据 |
| UAT | 相机内存/存储 | 鉴权成功后服务端返回 | API 调用身份验证 |

## 安全要点

- Secret 通过蓝牙传输（非 WiFi），避免中间人攻击
- UAT 有时效性，降低泄露风险
- 鉴权失败/订阅失效 → 停止同步 + 提示用户去 APP 处理
