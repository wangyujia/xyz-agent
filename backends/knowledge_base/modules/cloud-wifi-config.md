# 云服务 WiFi 配置与连接

## 概述

相机通过 STA 模式连接公网 WiFi，是云服务的网络基础。支持相机本机配置和手机远程配置两种方式。

## 1. 相机本机配置

**入口**：设置 > WIFI设置 > 连接至互联网

- 进入后自动检索附近 WiFi，超时 30s
- 提供刷新按钮，可重新启动检索
- 用户手动选择接入点 SSID

## 2. 手机配置（通过蓝牙）

**入口**：设备设置 > 相机 WIFI 设置

流程：
1. APP 自动检索附近 WiFi（30s 超时，可刷新）
2. 用户选择 SSID → 弹出密码输入界面
3. APP 通过**蓝牙**将 SSID + 密码发送至相机
4. 相机执行连接：
   - ✅ 成功：蓝牙回传成功协议 → APP 展示成功 → 相机存储凭据
   - ❌ 失败：蓝牙回传失败协议 → APP 展示失败 → 需重新选择

## 3. 多网络配置存储

- 固件支持存储**最多 5 组** WiFi 配置 (SSID/密码)
- 超出 5 组时，最新配置**覆盖最旧**配置

## 4. 自动重连

触发条件：
- 用户手动启动云服务需连接公网
- 相机处于充电状态需自动连接

行为：自动扫描并尝试连接已存储的 WiFi 网络

## 5. 连接状态展示

相机页面显示清晰图标，实时展示三种状态：
- 🔴 未连接
- 🟡 正在连接
- 🟢 已连接

## 关键参数

| 参数 | 值 |
|------|-----|
| WiFi 检索超时 | 30s |
| 最大存储组数 | 5 组 |
| 通信方式（手机→相机） | BLE 蓝牙 |
| 溢出策略 | FIFO（最旧覆盖） |
