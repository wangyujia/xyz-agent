## 云服务入口

### 1. 在下拉菜单新增云服务入口

已开通和未开通的状态在 UI 界面呈现上需有明显的差别。

#### 1.1 开通状态
- 自动检测并显示待云同步的文件数量及文件大小
- 立即同步：触发同步的前置校验，校验成功后开始自动云传输流程
- 同步设置：触发云服务设置

#### 1.2 未开通状态
- 云服务介绍
- 引导开通路径
- 未开通文案：订阅 Leaptic 云服务，享自动备份、云端智能剪辑、超值加密大空间！请前往 Leaptic APP 开启订阅

### 2. 相册增加云服务能力——手动同步
支持用户在相册图库多选页及大图预览页进行云同步。
当用户选择相关文件点击同步后，触发同步的前置校验，校验成功后开始云传输流程。

## 云服务设置

### 1. 我的账号
- 显示用户已绑定的账号信息
- 当用户在 APP 端解除绑定后，需要在 UI 界面提示 "账号已解绑"

### 2. 我的 Wi-Fi
- 默认展示已连接的 Wi-Fi 信息
- 点击后展示当前可连接的 Wi-Fi 列表，置顶当前已连接的 Wi-Fi；最多展示 5 组
- 仅支持手动切换/删除
- 固定在下方提示连接 Wi-Fi 路径：可前往 Leaptic APP 进行 Wi-Fi 配置

### 3. 自动同步
- 相机自动同步（默认开）
- 存储卡自动同步（默认开）
- 相机/存储卡的自动同步开关均为开时，自动同步优先上传相机文件

### 4. 自动同步时机
默认为充电优先。
- 充电优先（电量达到 80% 及以上后开始同步）
- 同步优先（电量达到 40% 及以上后开始同步）

### 5. 自动同步顺序
默认为最早拍摄。
- 最早拍摄（时间从远到近）
- 最近拍摄（时间从近到远）

### 6. 自动删除
- 相机自动删除（默认关）
- 存储卡自动删除（默认关）
